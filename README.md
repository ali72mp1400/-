# RSMH 1.1.0

کلاینت VPN سبک بر پایه‌ی sing-box (libbox).

## تغییرات این نسخه
- **ظاهر جدید** (سبز/مشکی): دایره‌ی اتصال با موج‌های زنده که با سرعت ترافیک بالا و پایین میرن، تایمر بزرگ، سرعت دانلود/آپلود و مصرف کل.
- **Smart**: دکمه‌ی «هوشمند» بهترین ۸ سرور رو خودکار انتخاب و failover میکنه. دو کاشی‌ی کنار اون، پرتعدادترین کشورها (از اسم/پرچم سرورها) هستن.
- **منابع**: ۶ لیست گیت‌هاب + ۷ لیست دیگه + ۳ کانال تلگرام (تنظیمات ← منابع). آینه‌ی jsDelivr برای وقتی raw.githubusercontent بسته‌ست.
- **اینترنت ضعیف** (پیش‌فرض روشن): timeout بلندتر، سقف حجم دانلود، همزمانی کمتر، کش ۴۸ ساعته‌ی منابع، MTU کوچک‌تر، تست دوره‌ای کم‌تر، رد کردن QUIC.

## بیلد
مثل قبل: push روی GitHub و اجرای workflow «Build Android APK».
